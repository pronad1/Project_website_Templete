# Correct Answers, Unsafe Advice? (ACL manuscript)

## Compile on Overleaf (fast version, works on the free plan)
1. New Project > Upload Project > choose this zip.
2. Compiler: **pdfLaTeX** (Overleaf's default; Menu > Settings > Compiler). Do NOT use XeLaTeX for `main.tex`.
3. Recompile. The PDF has 35 pages: the main paper plus the appendix.

How it stays fast: `main.tex` is compiled with pdfLaTeX; the 20-page appendix (full of Bangla text) is attached as a
pre-built PDF (`appendix_prebuilt.pdf`); the two Bangla phrases in the main text are tiny pre-rendered images
(`bn_*.pdf`); figures are lossless PDFs; and the bibliography is pre-built (`refs_prebuilt.bbl`, so no BibTeX run).
References from the main text into the appendix keep their numbers and link to the right page (`appendix_labels.tex`).

### Editing
- **Main text** (`main.tex`): edit freely on Overleaf.
- **Citations:** if you add or change citations, replace `\input{refs_prebuilt.bbl}` with `\bibliography{refs}` near the
  end of `main.tex`; Overleaf then runs BibTeX automatically (slightly slower compiles).
- **Appendix:** its source is in `main_full_xelatex.tex` (appendix part), `appendix/`, and `tables/`. After editing it,
  rebuild the fast version locally with XeLaTeX installed: `python scripts/build_overleaf.py` (regenerates
  `main.tex`, `appendix_prebuilt.pdf`, `appendix_labels.tex`, `refs_prebuilt.bbl`, `bn_*.pdf`). Note: this overwrites
  `main.tex` from `main_full_xelatex.tex`, so make main-text edits in `main_full_xelatex.tex` too, or copy them over.
- If you add tables or figures to the main text, the numbers of later appendix tables/figures would shift; rebuild
  with the script so both stay consistent.

## Full XeLaTeX version (local, or Overleaf paid plans)
`main_full_xelatex.tex` is the complete single-source paper. Compile with XeLaTeX:
`xelatex main_full_xelatex && bibtex main_full_xelatex && xelatex main_full_xelatex && xelatex main_full_xelatex`.
Noto Sans Bengali is bundled in `fonts/` (SIL Open Font License); TeX Gyre Termes and DejaVu Sans Mono come with TeX Live.
Set `\appendixfalse` near the top to compile only the main paper while editing.

## Before submitting
- Replace the author names, affiliation, and e-mails (`\author{...}`) in `main.tex` (and `main_full_xelatex.tex`).
- For anonymous ARR review, change `\usepackage[final]{acl}` to `\usepackage[review]{acl}` and anonymise or remove the
  Acknowledgments. (For review mode, rebuild the appendix PDF with the same option.)

## Files
- `main.tex` (fast pdfLaTeX version), `main_full_xelatex.tex` (complete XeLaTeX source), `refs.bib`, `refs_prebuilt.bbl`.
- `acl.sty`, `acl_natbib.bst`: official ACL style files. `fig_method.pdf`: method overview.
- `figures/`: result figures (PNG for the XeLaTeX version, lossless PDF for the fast version).
- `tables/`, `appendix/`: generated from the analysis outputs and code (prompts verbatim).
- `appendix_prebuilt.pdf`, `appendix_labels.tex`, `bn_chest_xray.pdf`, `bn_cicix.pdf`: generated by `scripts/build_overleaf.py`.
- `scripts/`: `gather.py`, `build_tex.py`, `build_appendix.py`, `wrap_bn.py`, `build_overleaf.py`, `prompts.json`.

All numbers come from the final results (`bmc_results_FINAL_20261004.zip`, `runs/analysis/`).
